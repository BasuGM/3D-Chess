# M1 — Foundation and shell

Next.js, Tailwind, Vitest, Testing Library, Playwright, and strict TypeScript are in place. The page is a full-bleed charcoal stage with the wordmark, status line, player cards, scoresheet, dock, and mobile sheet. Gold is limited to the active ply, selection, and the wordmark rule.

Checked at a desktop width and at 390px. Focus rings use the gold outline. The canvas mounts after hydration so the server markup matches the first client render.
